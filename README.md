# RescueDesk AI

Local-first, offline-capable emergency-preparedness assistant for the AppBuildersPH Hackathon 2026. Ask questions about bundled emergency-preparedness documents and get answers generated by a language model running **entirely on your device** — no cloud AI in the core path.

> Note: this repo's folder is `local_ai`. The product name is **RescueDesk AI** (per `prd.md`), which supersedes the earlier working title.

## Docs

- [`phasing.md`](./phasing.md) — build phases vs PRD §14

## What runs locally
Document extraction, indexing, BM25 retrieval, model inference, checklist, and chat history all run on-device. Internet is needed **once** to install dependencies and download the model.

## Quickstart (backend API only — no UI yet)
The MVP is a loopback HTTP/JSON service you can `curl`.

**Windows**
```powershell
# Prereqs: Python 3.10+, then Ollama + a small model
winget install Ollama.Ollama
ollama pull llama3.2:3b

cd backend
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\setup.ps1
.\run.ps1
```

**macOS / Linux**
```bash
brew install ollama && ollama serve   # in another terminal
ollama pull llama3.2:3b
cd backend && ./setup.sh && ./run.sh
```

**Test it**
```bash
curl http://127.0.0.1:5057/api/health
curl -X POST http://127.0.0.1:5057/api/documents \
  -H 'Content-Type: application/json' \
  -d '{"path":"data/sample/typhoon_prep_sample.txt"}'
curl -X POST http://127.0.0.1:5057/api/ask \
  -H 'Content-Type: application/json' \
  -d '{"question":"how much water should i store per person"}'
```

## Disclaimer
RescueDesk AI is a preparedness reference tool, **not** an emergency dispatch or live alert service. Always follow current instructions from official authorities and contact local emergency services when necessary.
